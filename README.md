## 📌 About the Internship

The virtual internship focused on applying advanced data analytics, predictive modeling, and Generative AI principles to real-world financial services problems. Acting as an AI Transformation Consultant for a simulated client (Geldium), the project involved exploratory data analysis (EDA), designing a machine learning model for credit delinquency prediction, and formulating a proactive, AI-driven collections strategy.

**Organization:** Tata Insights and Quants (Tata iQ) — Hosted via Forage.

## 🎯 Objectives

* Perform Exploratory Data Analysis (EDA) to identify patterns in financial datasets.
* Design a structured machine learning model plan to predict credit default risk.
* Formulate an AI-driven, segmented collections strategy based on predictive analytics.
* Develop an executive briefing outlining the deployment of an autonomous, responsible AI system.
